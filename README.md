# Albion Ledger v1.5

Зафиксированная версия: **v1.5** (1.5.0), 17 октября 2026. Состав и ограничения — [CHANGELOG.md](CHANGELOG.md). Машиночитаемый номер версии — [version.json](version.json).

Архив проекта и Git-тег не сохраняют личные данные браузера. Запасы и бухгалтерию экспортируйте отдельно в CSV.

## Лимит груза

В «Условия торговли» задаётся максимальный вес в килограммах и вес вещей, занятый вне этого плана. Пустой лимит — без ограничения, 0 — нулевая доступная вместимость. Используйте свою допустимую грузоподъёмность с учётом маунта и сумки; персональные модификаторы автоматически не рассчитываются.

Режим «Весь груз» проверяет больший из весов исходных предметов с материалами и готовых предметов после улучшения. Собственные запасы, включённые в план, также имеют вес. Режим «Только новая закупка» учитывает лишь недостающие компоненты. Эти режимы дают разные ограничения: режим закупки сам по себе не гарантирует вместимость всего имущества на персонаже.

Стратегии, автоподбор, ручное добавление и увеличение количества учитывают лимит. Уже существующий план при уменьшении лимита не удаляется, но показывает превышение и не записывается в журнал до исправления. В плане и карточках направлений показаны веса до/после улучшения, вес новой закупки и остаток. Источник — @weight из снимка ao-data/ao-bin-dumps/items.json от 17.10.2026. Есть данные для 10 435 из 10 439 позиций. Неизвестный вес не принимается за нулевой и исключает подбор при заданном лимите. Весовой массив проверяется на совпадение с порядком каталога.

## Стратегии, запасы и подробная бухгалтерия

Главный экран сравнивает найденные направления перевозки, зачарования и зачарования с перевозкой. «Лучший город сбыта» проверяет все городские рынки и Чёрный рынок, в пределах выбранных предметов и доступных цен. Каждое направление — отдельный сценарий с бюджетом и до 20 разными позициями по одной штуке. Сортировка по расчётной прибыли, не доказанный оптимум. Время и расходы на дорогу вводятся пользователем; ожидание ордеров неизвестно. Крафт с возвратом ресурсов и фокусом пока не включён.

Карточка сделки показывает точные даты наблюдений покупки, продажи и материалов, источник AODP, качество, налог и формулу. Признаки аномалии — доходность выше 100% или сбыт выше медианы доступных городских цен более чем втрое (минимум три наблюдения). Разница цен ЧР и городов сама по себе не доказывает ошибку. Признаки можно скрыть или показать; отсутствие предупреждения не гарантирует исполнение.

«Мои запасы»: ручной ввод и CSV с полями server,city,item_id,quality,quantity,unit_cost. Сервер: europe/west/east, город на английском. unit_cost необязателен. Импорт прибавляет количества и проверяется целиком до изменения записей. Повторный импорт повторно увеличивает запасы. Есть шаблон и экспорт. Автоматического чтения игрового банка нет.

План резервирует запасы по серверу, городу, ID и качеству, не расходуя один остаток дважды. Новая закупка и стоимость всех компонентов показаны отдельно. Запасы физически не списываются. Известная цена приобретения используется для предварительного журнала; неизвестная заменяется явно отмеченной рыночной оценкой. Рыночная прибыль плана остаётся по стоимости всех компонентов. Старый план без состава нужно пересобрать.

Бухгалтерия хранит покупку, материалы, дорогу, прочие расходы, выручку до комиссий, налог, выставление и перевыставления, время и статус рейса. Старые записи сохраняют прежнюю выручку после комиссий с нулевыми дополнительными комиссиями, чтобы не вычесть налог повторно. Планы требуют внесения фактических сумм до завершения. Статистика учитывает только завершённые рейсы; среднее серебро в час — по сумме прибыли и времени рейсов с указанным временем. Есть экспорт бухгалтерии CSV.

Реализация самостоятельная: finance.js — чистые расчёты, holdings.js — запасы и CSV, features.js — стратегии, источники и журнал. Идеи сопоставлены с epaprat/albion-ledger; его код не включён. Учёт и профиль локальны для браузера и не синхронизируются между устройствами.

Готовый статический сайт. Откройте ../Albion-Ledger.html или разместите содержимое этой папки на HTTPS-хостинге. Установка зависимостей не требуется.

Каталог содержит 10 439 позиций из https://github.com/ao-data/ao-bin-dumps (items.json и formatted/items.json), все 16 категорий рынка, русские названия, тиры и варианты зачарования. Позиции, явно помеченные скрытыми или неторгуемыми, исключены. Сводка снимка — catalog-summary.json.

Цены загружаются из Albion Online Data Project: https://www.albion-online-data.com/ . Проверяется возраст покупки, продажи и материалов. Количество по лучшей цене неизвестно и проверяется в игре.

Фильтры выбирают точные позиции. Большие подкатегории раскрываются кнопкой «Показать ещё». Поиск по названию и ID. Все категории доступны; для Чёрного рынка автоматически исключаются неподходящие товары. Для скакунов, расходников, материалов, мебели выбирайте обычный город продажи. Полный поиск может идти несколько минут; есть остановка с частичным результатом.

Зачарование до .3 использует реальные upgraderequirements из каталога. Позиции без рецепта не улучшаются. Товары без качества проверяются как обычные, товары с качеством — по выбранному уровню.

Прибыль = цена продажи × (1 − налог − комиссия выставления) − закупка − материалы. Комиссия выставления 2,5% учитывается только в режиме ордера продажи. Повторное выставление, транспорт и риск гибели не учитываются автоматически. Автоподбор корзины — эвристика, по одной штуке разных позиций (до 20), с положительным результатом при падении цены на 10%.

Профиль, корзина и журнал хранятся в браузере и не синхронизируются между устройствами. Онлайн-сайт можно открывать на разных устройствах; записи пока отдельные. Крафт с возвратом ресурсов, фокусом и налогом станка пока не реализован.

## GitHub Pages

Загрузите файлы этой папки в корень репозитория. Settings → Pages → Source → Deploy from a branch → main → /(root) → Save. После успешной публикации ссылка появится в Pages. Репозиторий Public подходит для бесплатного публичного сайта; его исходники также будут открыты.

Проверены все категории, уникальность ID, рецепты, качество, комиссии, свежесть материалов, исключение неподходящих категорий ЧР и размеры запросов. Визуальная проверка локального файла инструментом браузера ограничена политикой file://.

Неофициальный проект, не связан с Sandbox Interactive. Каталог — снимок игровых выгрузок сообщества, не автоматически обновляемая база.
