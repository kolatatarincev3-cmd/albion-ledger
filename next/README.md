# v1.6 — подключённые модули

Модули подключены к плану закупки через ui.js. Стабильная v1.5 сохранена в GitHub Releases для отката.

- `liquidity.js`: история sell orders, наблюдавшиеся и пропущенные дни, среднее по наблюдавшимся дням, взвешенная цена, свежесть. Пропущенные дни не подменяются нулём. История не подтверждает глубину ордеров и немедленный спрос ЧР.
- `quantity.js`: увеличение количества под бюджет и грузоподъёмность, с резервированием своих запасов. Без ручного подтверждения доступного количества — максимум одна штука. Исторический лимит не превращается в подтверждённый объём, а для немедленной скупки вообще не применяется. Алгоритм эвристический, не гарантирует оптимум.
- `preflight.js`: повторная оценка готовой корзины по точным ID, городу и качеству. Пропавшая, устаревшая или некорректная цена блокирует общий новый итог. Корзина не изменяется автоматически.

Интерфейс: загрузка истории только для текущего плана или первых 40 видимых кандидатов, подтверждение размера партии, подбор количества, сравнение старой и новой прибыли и явное применение обновлённых цен. Без подтверждения количества — максимум по 1 шт. Перепроверка не гарантирует наличие товара. Крафт остаётся отдельной будущей задачей.

Контракт источника: https://www.albion-online-data.com/api/ — history относится к sell orders. Реальный ответ истории T4_BAG/Lymhurst проверен 17.10.2026: даты в ответе могут отставать от текущей даты, поэтому покрытие и свежесть обязательны.

Проверки: `node next/test.cjs` из корня проекта. Это тесты расчётов; сетевую доступность и интерфейс они не подтверждают.
