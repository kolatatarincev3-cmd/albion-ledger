# Albion Ledger v1.7 beta — сервис подписок

Отдельный экземпляр Node.js 24 LTS с постоянным диском. Он обслуживает сайт и API на одном домене. GitHub Pages остаётся старой бесплатной версией. Публичной админки и API выпуска ключей нет: владелец выпускает ключи только через SSH/консоль сервера. Покупателю доступны регистрация, вход и активация. FunPay не подключён автоматически; выдача вручную после подтверждения оплаты.

## Запуск

1. Разместить проект на собственном сервере с Node.js 24.15+ (ветка 24), постоянным диском и HTTPS reverse proxy. Указать PUBLIC_ORIGIN=https://ваш-домен, DATA_DIR=/абсолютный/постоянный/путь, PORT=8787. Прокси передаёт только на 127.0.0.1:8787. API и сайт должны иметь один origin.
2. Запустить `npm test`, затем `npm start` под отдельным системным пользователем. Ограничить доступ к DATA_DIR этому пользователю; настроить резервные копии SQLite штатным online backup либо остановленным сервисом вместе с WAL-файлами. Не публиковать папку проекта целиком другим веб-сервером.
3. На сервере в той же папке и с тем же DATA_DIR выполнить `node server/admin.cjs issue FUNPAY-НОМЕР-ЗАКАЗА 30`. Сгенерированный ключ показывается один раз в консоли: передать покупателю приватно через заказ. Не включать запись вывода консоли. Номер заказа уникален. Не сохранять ключ в репозитории или открытой таблице. База хранит только SHA-256 ключа.
4. Ключ добавляет срок при активации к текущему окончанию, либо к текущей дате. Повтор на том же аккаунте не добавляет дней; другой аккаунт получит отказ. Для непроданного/утраченного ключа: `node server/admin.cjs revoke-unused FUNPAY-НОМЕР-ЗАКАЗА`. После этого выдать замену с отдельным номером-суффиксом. Возвраты активированных подписок требуют отдельного регламента и пока не автоматизированы.
5. Прежде чем открывать продажи, проверить настоящий HTTPS, активацию, продление, восстановление базы и письмо/поддержку для восстановления аккаунта. Пока нет восстановления пароля, подтверждения email, удаления аккаунта, автоматизации FunPay, уведомлений и облачного журнала. Бета не объявляется готовым коммерческим релизом.

## Локальная проверка

PUBLIC_ORIGIN=http://127.0.0.1:8787, DEV_HTTP=1; `npm start`. HTTP-режим только на локальном компьютере. В production cookie Secure; сессия на 7 дней, HttpOnly и SameSite=Strict. POST проверяет Origin; HTML/JS не содержит секретов или списка ключей.

## Доступ

Все инструменты v1.6 остаются бесплатными. Pro разрешает серверную запись одного снимка плана закупки. Чтение собственного снимка доступно после истечения подписки. Снимок скачивается JSON, автоматического переноса в корзину пока нет. Права на запись проверяются сервером при каждом запросе. Изменение интерфейса браузера не даёт серверных прав.

Ограничитель запросов рассчитан на один процесс; за общим reverse proxy учитывает адрес прокси, поэтому при росте аудитории требуется ограничение на входном прокси с доверенными адресами и общий счётчик. Не доверять произвольному X-Forwarded-For. Не запускать несколько процессов с независимыми лимитами. Не обещать актуальность цен, безопасность перевозки или гарантированную прибыль.
